# Data provenance and terms

The files in `data/` are small genomic-region subsets re-distributed here solely to
make the analysis reproducible. They are derived from public resources; please cite
and respect the terms of the original sources:

- cis-eQTL summary statistics — eQTL Catalogue (CC-BY 4.0).
- CAVS, PAD outcome GWAS — FinnGen (https://www.finngen.fi/, release terms apply).
- CAD outcome GWAS — CARDIoGRAMplusC4D via GWAS Catalogue (harmonised).
- LD reference (data-acquisition module) — UK Biobank LD blocks (Alkes group).

The derived region files are shared under CC-BY 4.0 with attribution to the sources
above. The code is licensed separately (see LICENSE, MIT).
